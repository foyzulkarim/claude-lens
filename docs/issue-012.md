# Issue #12 — Data inventory (observed-field evidence)

**Plan task:** #P0-7 · **Phase:** 0 · **PR(s):** #57 · **Closed:** 2026-07-10 · [GitHub issue #12](https://github.com/foyzulkarim/claude-lens/issues/12)

Built the consolidated field corpus for Claude Lens from real `~/.claude` transcripts, split into two
companion specs so Phase-2 API work could reuse them instead of re-scavenging the JSONL:
`specs/claude-lens-data-model.md` (the evidence layer — every observed field across T/C/B/L line
types, presence counts, anonymized examples, regenerated by `scripts/survey-fields.py`) and
`specs/claude-lens-field-definitions.md` (the meaning layer — field definitions, a relationships/
join-key map, value-domains, confidence markers, cited sources). Kept as two files on purpose so the
inventory stays regenerable and interpretation never contaminates the evidence.

## Outcome

Inventory covers every observed line type as a first-class field table with anonymized example
values; C/B/L each have dedicated tables; C-vs-L collisions documented. Definitions doc documents
each field's meaning with confidence markers and a join-key map. Both specs remain living V2 docs
under `specs/` (not mirrored here — this hub only records the issue's closure); `#P2-1` cites the
inventory as the field source-of-truth. Unblocked #P0-3 (fixtures must exercise the surveyed fields).
