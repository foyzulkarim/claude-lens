# Claude Lens — Issue Archive

Finished-issue artifacts — requirements, architecture, and code-review docs — land here once their
issue closes and its working copy is retired from `specs/`. Layout convention:
`specs/wiki-structure.md` in the main repo. Each issue gets one hub page below; its documents hang
off the hub, not off this index. Issues are grouped by phase (mirrored from `specs/claude-lens-plan.md`
— ✓ done / ◐ in progress) and sorted by issue number within each group; issues with no plan-task ID
land under Unphased.
