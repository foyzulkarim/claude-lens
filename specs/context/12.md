# Task 12: #P0-7 — Data inventory (observed-field evidence)

- **Type:** feat · **Source:** GitHub issue #12 · **State:** OPEN · **Labels:** phase-0

## Summary

Two companion specs form the consolidated field corpus for Claude Lens, built from the real
`~/.claude` transcripts so Phase-2 API work reuses them instead of re-scavenging the JSONL:

- **`specs/claude-lens-data-model.md`** — the **evidence** layer: every observed field across
  T (`<uuid>.jsonl`), C (`<uuid>.cost.jsonl`), B (`<uuid>.turn-boundaries.jsonl`), and
  L (`cost-log.jsonl` at `~/.claude/`), with name, JSON type, presence (n/N), and one inline
  anonymized example. Pure evidence — regenerated by `scripts/survey-fields.py`.
- **`specs/claude-lens-field-definitions.md`** — the **meaning** layer: what each field means,
  a relationships/join-key map, recalled value-domains, per-field confidence markers
  (✅ known / 🔶 inferred / ❓ guess), and cited sources. Kept in a separate file on purpose, so
  the inventory stays regenerable and interpretation never contaminates the evidence.

## Scope

- **Inventory (evidence-only)** — all 21 transcript line types incl. `system/*` subtypes; nested
  objects (`message.*`, `usage.*`, `cache_creation.*`, `iterations[0].*`, `hookInfos[0].*`,
  `compactMetadata.*`) to two levels; content-block shapes (text / thinking / tool_use /
  tool_result); per-tool `tool_use.input` keys. Dedicated first-class tables for C/B/L. Cross-tier
  (C vs L) name collisions documented, not reconciled.
- **Definitions (meaning)** — big-picture model overview; relationships & join keys
  (within-transcript links + cross-file C/B/L→T joins); shared-envelope glossary; per-line-type
  meaning mirroring the inventory; value-domains/enums; confidence markers; sources.
- **Not covered here** — `CompactCall`/`Turn`/`Session` contracts, derivation rules, measure
  formulas, API envelopes, behavior contracts, sign-off gates, and tier (🟢/🟡/🔴) assignment.
  These belong to `#P2-1`.

## Acceptance criteria

- Inventory covers every observed line type as a first-class field table with anonymized example
  values; C/B/L each have dedicated tables; C-vs-L name collisions documented.
- Definitions doc documents the meaning of each inventoried field, with confidence markers, a
  join-key map, value-domain caveats, and cited sources.
- Downstream `#P2-1` cites the inventory as the field source-of-truth.

## Deliverables (files) — for mapping a diff to scope

- `specs/claude-lens-data-model.md` — the evidence inventory (cross-links to the definitions doc).
- `specs/claude-lens-field-definitions.md` — the meaning layer.
- `scripts/survey-fields.py` — the survey script that regenerates the inventory; its anonymizer
  collapses newlines/tabs and escapes `|`, so example values are single-line and never break a
  markdown table.

## Deferred — intentional, not gaps

- **Enum verification** — value-domains are recalled; a `survey-fields.py --distinct-values` pass
  to confirm them against the corpus is parked.
- **Measures / derivation / tier assignment** — `#P2-1`'s scope, not this task's.

## Dependencies

- Depends on: none — spec-only; can run in parallel with #P0-2.
- Unblocks: #P0-3 (fixtures must exercise the surveyed fields); #P2-1 cites the inventory as field
  source-of-truth.
