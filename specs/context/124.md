# Task 124: feat: cache scorecard — per-session hygiene grade + Biggest Lever dashboard card

- **Type:** feat

## Description


Derived from [specs/requirements/REQ-124-cache-scorecard.md](../blob/main/specs/requirements/REQ-124-cache-scorecard.md) (Phase 1 requirements, 2026-07-27). That doc carries the full behaviors, edge-case decisions, and decisions log; this issue is the contract.

## What & why

Add a per-session **cache scorecard**: quantify cache-creation tokens that were re-writes of already-cached content ("waste"), attribute each waste event to a cause via the app's existing cache-cause classification, and roll fixable events up into a letter **hygiene grade** (idle/TTL expiry cost is shown as informational, never graded). Surface it as a Session Detail scorecard section and one dashboard card — **"Biggest lever this week"**, the single largest waste event in the active time range, with cause, token/dollar consequence, and a deep link.

Why: the dashboard currently shows state with no deviation, cause, or consequence — nothing invites investigation. A prototype scan (`specs/session_scorecard.py`) of 97 real sessions found 72.5% of cache-creation tokens (20.2M) were re-writes, and a re-write costs ~12.5× a cache hit. No existing tool surfaces this; it builds directly on the K2 classifier and is the product's most differentiated insight.

## Acceptance

Copied verbatim from the REQ doc (R1–R10, N1–N3):

- **R1** — For a synthetic fixture session with a known bust pattern, the computed decomposition and event list match hand-calculated expected values exactly.
- **R2** — For the same fixture call, the scorecard event's cause equals the cause shown by existing cache-cause surfaces (same classification, same inputs → same output).
- **R3** — A fixture session whose only waste is idle-expiry re-writes grades the same as an otherwise-identical session with no waste; adding one prefix bust lowers the grade.
- **R4** — A 9-call fixture session returns metrics and no grade with the too-short reason; an 11-call session returns a grade. Changing the configured floor changes the boundary.
- **R5** — With < 20 graded sessions, a fixture fleet grades on documented default bands. With ≥ 20, the same session's grade reflects the fleet-calibrated bands, and a fleet where all sessions are similar does not grade them all F.
- **R6** — On a fixture session, the section renders grade, metrics, and one row per waste event; clicking an event lands on that turn; an unexplained event displays "unexplained", not a guessed cause.
- **R7** — With fixture data containing multiple waste events, the card shows the largest one in the selected range with cause, token count, dollar estimate, and a working deep link; changing the time range changes the selection accordingly.
- **R8** — With fixture data containing zero waste events in range, the card renders the positive state with real period numbers; it is visually distinct from a loading/error state.
- **R9** — Appending fixture lines that introduce a bust to a session being viewed updates the visible scorecard without a page reload.
- **R10** — For a model with no pricing data, the card/section shows the token count with cost marked unavailable — not `$0.00`.
- **N1** — Scorecard output is identical for a fixture session with and without premium sidecar files present.
- **N2** — The existing ingest benchmark (`npm run bench:ingest`) shows no material regression after the feature lands.
- **N3** — Running the engine twice over the same fixture yields byte-identical results.

## Scope notes

- In scope: engine, Session Detail section, Biggest Lever card, grade floor + fixed-then-calibrated bands (thresholds configurable alongside gate thresholds), live-update, and recording the algorithm/thresholds/evidence contract in `specs/gates.md` (domain owner for Report Card scoring).
- Out of scope (queued as follow-up REQs): repeat-offender / weekly-trend / fixable-vs-weather cards, parser capture of context events (permission grants, skill loads), fleet trend measures, premium enrichment, recommendations, gamification.
- Transcript-only (🟢 tier). Fixtures must be synthetic — never copied from real transcripts.
