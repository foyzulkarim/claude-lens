Task **#P2-3** from [specs/claude-lens-plan.md](../blob/main/specs/claude-lens-plan.md) — Phase 2.

## Summary
File discovery (fast-glob + T/C/B/L filename classification) and the two-speed polling loop that notices growth and brand-new session files.

## Scope
- `discovery.ts` (fast-glob over roots, filename classification T/C/B/L) and `poller.ts` (fast stat loop 2–5s, slow re-glob ~30s). Mid-run discovery registers brand-new session files.
- The L file (`cost-log.jsonl`) is discovered at `~/.claude/` — the parent of the default projects root, outside the projects glob — discovery checks it separately (architecture §4).
- Filename classification enforces the dot-separated convention (`<uuid>.cost.jsonl`, `<uuid>.turn-boundaries.jsonl`); underscored variants are not accepted (architecture §4).

## Acceptance criteria
- unit tests for classification; a file created after boot is picked up within one slow-loop interval.
- a session whose source file is deleted is removed from the store on the next discovery pass.
- overlapping scan roots do not create duplicate sessions (dedupe by absolute file path).
- the app boots cleanly when a configured scan root does not exist or contains no `.jsonl` files (empty state, no crash).
