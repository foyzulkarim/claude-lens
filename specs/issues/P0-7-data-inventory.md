Task **#P0-7** from [specs/claude-lens-plan.md](../blob/main/specs/claude-lens-plan.md) — Phase 0.
Local context: [`specs/context/12.md`](../blob/main/specs/context/12.md) is the current source of truth for scope.

## Summary

Survey every observed field across T (`<uuid>.jsonl`), C (`<uuid>.cost.jsonl`), B (`<uuid>.turn-boundaries.jsonl`), and L (`cost-log.jsonl` at `~/.claude/`) and produce two companion specs — the consolidated field corpus Phase-2 API work reuses instead of re-scavenging the JSONL:

- **`specs/claude-lens-data-model.md`** — the **evidence** layer: every field with name, JSON type, presence (n/N), and one inline anonymized example. Pure evidence, regenerated by `scripts/survey-fields.py`.
- **`specs/claude-lens-field-definitions.md`** — the **meaning** layer: field definitions, a relationships/join-key map, recalled value-domains, per-field confidence markers, and cited sources. Kept separate so the inventory stays regenerable.

## Scope

- Inventory (evidence-only): all 21 transcript line types incl. `system/*` subtypes; nested objects to two levels; content-block shapes; per-tool `tool_use.input` keys; dedicated C/B/L tables; cross-tier (C vs L) name collisions documented, not reconciled.
- Definitions (meaning): big-picture overview; join-key map (within-transcript + cross-file C/B/L→T); shared-envelope glossary; per-line-type meaning; value-domains; confidence markers; sources.
- Not covered here (→ `#P2-1`/`#P2-8`): `CompactCall`/`Turn`/`Session` contracts, derivation rules, measure formulas, API envelopes, behavior contracts, sign-off gates, tier assignment.

## Acceptance criteria

- Inventory covers every observed line type as a first-class field table with anonymized example values; C/B/L each have dedicated tables; C-vs-L collisions documented.
- Definitions companion documents each field's meaning with confidence markers and a join-key map.
- Downstream `#P2-1` cites the inventory as the field source-of-truth.
